WORKSPACE GUIDE

Observe. Annotate. Recover.

Raw LiDAR shows the latest scan in the robot frame. It is not a persistent SLAM map.

This is a development search-and-rescue demonstrator. The software stop is not a safety-rated hardware emergency stop. Movement is locked by default. After server-side approval and explicit arming, hold WASD, arrow keys, or a directional button. Release to send zero velocity. Space stops this dashboard’s commands.

The ROS node independently stops and disarms on stale commands, expired browser heartbeats, connection loss, or a competing motor publisher.

Snapshots use approximate timestamp matching. A capture with a missing or stale camera is labeled partial. Mock data and mock AI responses are always labeled.
